# Linear Algebra Lab

An interactive presentation for the QMB 6875 linear-algebra mini-lectures (Version 3).

- **Person 1:** vectors, matrix multiplication, eigenvalues and eigenvectors, spectral and Cholesky decompositions, the inverse. Type in any symmetric 2×2 matrix and every slide updates.
- **Person 2:** a two-output firm whose profit is a quadratic form. Sliders for demand, costs and the cost link; live optimum and iso-profit curves.
- **Person 3:** quadratic forms and their level sets: circle, ellipse, lines, hyperbolas; plus the bivariate-normal / regression picture.

**Controls:** ← → to move between slides, `N` for speaker notes, `F` for full screen.

The whole thing is one file, `index.html`, with no build step. Open it in any browser, or host it with GitHub Pages.
